# 📊 Superstore Sales Analysis Dashboard

## 📌 Project Overview
This project analyzes Superstore sales data using Tableau, Excel, and MySQL to uncover sales trends, profit performance, customer segments, and regional insights. The interactive dashboard helps businesses make data-driven decisions through clear and effective visualizations.

## 🛠️ Tools & Technologies
- Tableau
- Microsoft Excel
- MySQL

## 📈 Dashboard Features
- Total Sales Analysis
- Total Profit Analysis
- Order Analysis
- Sales by Category
- Sales by Sub-Category
- Regional Sales Performance
- Customer Segment Analysis
- Monthly Sales & Profit Trends
- Interactive Filters and Visualizations

## 📁 Files Included
- Superstore Sales Analysis.twbx
- Superstore Dataset.xlsx
- SQL Queries.sql
- Dashboard Screenshot.png
- README.md

## 🔍 Key Insights
- Identified top-performing product categories and sub-categories.
- Compared sales and profit across different regions.
- Analyzed customer segments to understand purchasing behavior.
- Tracked monthly sales and profit trends.
- Built an interactive Tableau dashboard for business decision-making.
